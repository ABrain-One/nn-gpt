Let's think step by step and design a model for the real-world image denoising task. The solution should include a full usable model. Start by outlining the needed components and then implement the code.

TASK
  Input : noisy RGB tensor of shape [B, 3, 256, 256], float32 already scaled to [0, 1].
  Output: denoised RGB tensor of the SAME shape, values in [0, 1].
  Data  : real smartphone photographs (noisy/clean pairs), NOT synthetic additive Gaussian noise.
          The noise is signal-dependent, spatially correlated and stronger in dark regions.
  Scored by PSNR on the Y (luminance) channel, BT.601, higher is better.


CONSTRAINTS - a model violating any of these is discarded automatically:
  1. Multiply-accumulate cost at 3x256x256 input MUST be <= 9053 MMac. This is an edge
     deployment budget, not a suggestion. Prefer depthwise-separable convolutions,
     downsampled processing and modest channel widths over deep full-rank stacks.
  2. Use ONLY standard torch / torch.nn / torch.nn.functional operators.
     Do NOT use torchvision, timm, or any pre-built or pre-trained model.
  3. The network must be fully convolutional and must accept arbitrary spatial sizes
     divisible by its downsampling factor. Do not hardcode 256 anywhere.
  4. Numerical stability is mandatory. The forward pass must never emit NaN or Inf.
     If you use normalisation, division or sqrt, include an epsilon. Clamp the output.
     A single non-finite value scores the entire run 0.0.


NORMALISATION - vary it deliberately, but only within the mobile-safe set:
  SAFE (use freely):
    * nn.BatchNorm2d      folds into the preceding conv at inference -> zero runtime cost,
                          fully supported by the TFLite GPU delegate.
    * no normalisation    trivially safe; many strong denoisers omit it entirely.
    * learned channel affine / LayerScale: a per-channel nn.Parameter scale (and optional
                          bias) applied elementwise. Pure elementwise -> delegate-clean.
    * weight standardisation applied to conv WEIGHTS (not activations): costs nothing at
                          inference because it is folded into the stored weights.
  AVOID (they convert, but force a CPU fallback and defeat the GPU delegate):
    * nn.LayerNorm, nn.GroupNorm, nn.InstanceNorm2d -- these need a runtime reduction over
      spatial/channel axes, and LayerNorm additionally needs a permute round-trip.
  Pick whichever of the SAFE options suits your design. Do not default to the same choice
  every time: normalisation is a real architectural axis and we want it varied.
