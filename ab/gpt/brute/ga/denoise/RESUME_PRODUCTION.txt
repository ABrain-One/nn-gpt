================================================================================
 RESUME THE DENOISE PRODUCTION RUN  (after session expiry / node teardown)
================================================================================
The production GA is RESUMABLE. It checkpoints after every generation
(seed_ga_P1_checkpoint.pkl) and caches every evaluated model
(seed_ga_P1_cache.json), so restarting CONTINUES from the last completed
generation — it NEVER starts from generation 0.

--------------------------------------------------------------------------------
WHAT SURVIVES WHAT
--------------------------------------------------------------------------------
- Session (Claude conversation) expires, node stays up  -> the run keeps going
  (it's nohup-detached). Nothing to do.
- Node / HPC allocation is TORN DOWN -> the run dies (so does the supervisor).
  You must re-run ONE command below when the node is back. It resumes from the
  last checkpoint; at most the in-flight generation's un-cached models re-run.

--------------------------------------------------------------------------------
TO RESUME (paste this one line; in a Claude Code prompt prefix with `! `):
--------------------------------------------------------------------------------
cd /home/s493053/thesis/nn-dataset && PYTHONPATH=/home/s493053/thesis/nn-dataset \
nohup bash /home/s493053/thesis/nn-gpt/ab/gpt/brute/ga/denoise/production_supervisor.sh \
  >> /home/s493053/thesis/nn-gpt/ab/gpt/brute/ga/denoise/production_supervisor.log 2>&1 &

The supervisor auto-restarts the run on any crash while the node is up, and stops
itself once the run prints "=== DONE in".
